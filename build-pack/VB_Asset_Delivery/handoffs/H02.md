# H02 — Gated stock-footage acquisition

**Original Tier 3 source:** ASSET_PLAN.md:137

**Status:** Handoff planned; no gated action performed.

## Purpose
Acquire only the selected, inspected footage through a permitted account/download route and retain the actual terms.

## Inputs
BROLL-01…BROLL-06 candidate reports and any selected archival source access blocks

## Agent-preparable work and handoff steps
1. Review the agent’s exact asset URL, chosen shot/timecodes, creator, license terms, and any price before proceeding.
2. The user handles login, CAPTCHA, required terms acceptance, and any purchase decision. Do not disclose credentials to an agent or put keys in the pack.
3. Save the original file plus evidence of the applicable license/permission and give the agent its actual local path.
4. After acquisition, the owner verifies dimensions, duration, and that the downloaded clip is the selected version. No watermark removal or mislabeled preview.

## Actual human/capability boundary
Account login, required consent, CAPTCHA, and any payment decision belong to the user.

Original “human-only” wording is preserved as the plan's boundary, not a claim that no authorized future agent can operate the tool. First establish available capabilities and real permission; do not bypass missing access or claim work happened.

## Expected return package
- Downloaded original or explicit no-acquisition result; creator/source/license evidence; exact local path.
- Scouting and acquisition statuses remain distinct.

## Acceptance and stop rules
- [ ] Required user decisions and permissions are documented.
- [ ] Returned paths refer to real files; source/rights/versions and review results are recorded.
- [ ] No secret, password, token, or unapproved paid action appears in the pack.
- [ ] This handoff is marked complete only for the actual action performed, not for a proposed workaround.

If blocked, record the exact missing file, account permission, decision, or local capability. Do not request the original attachments again; they are already in sources/.
