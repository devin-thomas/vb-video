## 2. External evidence (short excerpts only)

The quotes below are kept short on purpose. Full citations, access methods and retrieval hashes are in `provenance.json` under the same source IDs. "OCR" means the Internet Archive's machine OCR text of a scanned issue. It was not checked against the page image.

### Microsoft's own product records

- **S02 — Microsoft KB 31937, "Macintosh QuickBASIC 1.00 System Requirements"** (Wayback capture 2007-03-13; last reviewed 2006-11-21). This names the product "Microsoft QuickBASIC Version 1.00 for the Apple Macintosh". It requires a Macintosh Plus, SE or II with System 4.10 and Finder 5.50 or later.
- **S03 — Microsoft KB Q51412** (last modified 1989-12-12, via the kbarchive mirror). Its applicability list names every Microsoft BASIC for the Mac at that date:
  - "Microsoft QuickBASIC Version 1.00 for the Apple Macintosh"
  - "Microsoft BASIC Compiler Version 1.00 for the Apple Macintosh"
  - BASIC Interpreter versions 1.00, 1.01, 2.00, 2.10 and 3.00 for the Apple Macintosh

  No Visual Basic product appears.
- **S04 — Microsoft KB Q66491** (last modified 1990-11-13). In November 1990 the current versions were "version 4.50 for MS-DOS and version 1.00 for the Apple Macintosh".
- **S05 — Microsoft KB Q31789** (2001-05-07). Visual Basic is listed only "for MS-DOS" and "for Windows". The Mac entries are the BASIC Interpreter 1.0–3.0 and BASIC Compiler 1.0.
- **S06 — Microsoft KB Q181780** (2002-05-13). It mentions VBA "Beginning in Word 97 for Windows and Word 98 Macintosh Edition". This shows Visual Basic for Applications (VBA) inside Mac Word from Word 98.
- **S28 — Microsoft KB Q120506, "How Virtual Memory Works on a Power Macintosh"**. It applies to Excel for the Power Macintosh 5.0, and its body is credited to a comp.sys.mac.apps posting of 1994-10-06. Its list of shared libraries includes "The Visual Basic, Applications Edition, macro language".

### Period Mac trade press (MacWEEK, Internet Archive OCR)

- **S17 — MacWEEK Vol. 10 No. 5, 1996-02-05**, review of Oracle Power Objects: "the absence of Visual Basic for the Mac".
- **S18 — MacWEEK Vol. 10 No. 1, 1996-01-08**, year-end satirical list. The OCR reads "Microsoft has already [word missing] it won't do VB for the Mac". The OCR is garbled and the context is humor, so this is weak corroboration only.
- **S19 — MacWEEK Vol. 10 No. 22, 1996-06-03, p. 76**, Clifford Colby. Microsoft is "on target for a summer release of the Mac version of Visual Basic Script". The same page covers Visual C++ 4.0 Cross-Development Edition for Macintosh.

### Microsoft Mac Business Unit (MacBU) statements on VBA in Mac Office

- **S20 — Erik Schwiebert (MacBU developer), "Saying goodbye to Visual Basic", 2006-08-08** (Wayback). The MacBU announced that VB would be removed from the next Mac Office. Existing macros had been "compiled to PowerPC code".
- **S21 — Erik Schwiebert, "Saying hello (again) to Visual Basic", 2008-05-13** (Wayback). This quotes a MacBU press release headed "VBA Returns to Future Versions of Office for Mac".
- **S23 — Microsoft Learn archived blog, "Q&A: is Visual Basic returning to Office:Mac?", 2010-03-02.** Office:Mac 2011 "will support VBA", at version 6.5.

### Adjacent history (context for what the narration may be conflating)

- **S09 — Creative Computing, May 1985, p. 46**, Glenn Hart, "Microsoft Basic 2.0 for the Mac". A period review of Microsoft's Mac BASIC interpreter.
- **S15 — Andy Hertzfeld, folklore.org, "MacBasic"** (story dated June 1985). A first-hand account: Apple's own MacBASIC was cancelled and sold to Microsoft for $1 during the renewal of Apple's Applesoft BASIC license. It was never released.
- **S12 / S16 — secondary.** WinWorld and Jonathan Hoyle (macCompanion, May 2006) give QuickBASIC for Mac 1.00e as April 1992 and say it was never 32-bit clean. WinWorld says it was discontinued in 1995. Hoyle says Visual Basic was never ported to the Mac. None of these points was checked against a Microsoft primary source.
