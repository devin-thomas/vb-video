## External primary source used for verification (not copied into the asset)

**Commodore 64 User's Guide**, Commodore Business Machines, Inc. Internet Archive metadata gives the date as 1982 and describes the scan as "Commodore manual, 8th printing"; the printing date of this particular copy was not checked, so 1982 is the archive's date, not a verified one. Printed page 12; scan leaf n27.

- Item: https://archive.org/details/commodore-64-user-guide
- Page image: https://archive.org/details/commodore-64-user-guide/page/n27/mode/1up
- Accessed: 2026-09-15. Read at full scan resolution (3301 × 5100). The scan is not stored in this repository: it is Commodore's copyrighted manual and is used only as evidence.

Two screen illustrations on that page show the power-on text. Transcribed from the page image (line breaks as printed):

~~~~text
**** COMMODORE 64 BASIC V2 ****
64K RAM SYSTEM  38911 BASIC BYTES FREE
READY
~~~~

The archive's automatic OCR of the same page reads `S4K RAM S VST EM 3391 1 BASIC BVTES FREE` and `READV`. Those are OCR errors in the dot-matrix-style lettering; the transcription above was taken from the page image, not the OCR. No full stop after READY is visible in the printed illustration at scan resolution; that detail is recorded as not settled by this page. The manual illustration is a printed reproduction, not a screen capture, so it verifies the wording and the model, not the pixels.
