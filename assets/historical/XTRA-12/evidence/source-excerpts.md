Paraphrase of the relevant text (not a quote): the DOW is a Visual Basic add-in that generates data Classes and User Controls. A Single Record User Control shows one record's fields in TextBoxes, ComboBoxes and CheckBoxes. Lookup fields appear as combo boxes that display readable text. The appendix gives the sample GetPerson, GetCounty, GetCompanyCar and GetManager stored procedures whose fields appear in the figure.
