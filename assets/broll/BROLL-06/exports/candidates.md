# BROLL-06 — Pentium-era PC booting: candidate report

**Status:** scouted, motion reviewed in-page. No media acquired. Release blocked (R14 open).
**Accessed:** 2026-09-15.
**Shot wanted:** a period desktop PC powering on, with a plausible CRT and OS (BIOS POST, memory count, Windows 95/3.x startup). Horizontal, with an 8–12 s usable segment.

## Bottom line
- **No free clip shows a Pentium-era PC booting or a period power-on.** This is based on viewed frames, not page text.
  - The best free shot is a period CRT PC in a room, with no boot.
  - The only free footage of a real boot process is a low-resolution POST-card close-up.
  - The one free "power-on" clip is a modern LCD monitor, so it is rejected.
- **The leads that do show a period boot are YouTube videos and are rights-blocked (H02).** These are LGR's AST Advantage 622, whose creator describes it as a 100 MHz Pentium running Windows 95, and "Old computer boot up Windows 95".
- **How frames were viewed.** Clips were played in-page in the in-app browser, and screenshots were taken at preview size; nothing was saved. Frames were not inspected at full source resolution.

## Review questions
1. **Fallback when no free clip shows a boot.** Nothing free shows a period boot, so which should we do?
   - (a) Use the Pexels period set shot (optionally cut with the POST-code insert) and let narration carry "booting".
   - (b) Pursue creator permission for the LGR or Jaime Cobo Vicente footage via H02.
   - (c) Commission a separately approved, labeled stand-in (self-shot on real hardware, or AI-generated). This needs a new assignment.
2. **Third-party on-screen UI.** Windows 95/3.x splash screens are Microsoft-copyrighted UI, and BIOS vendor logos are third-party marks. Is incidental on-screen OS/BIOS UI acceptable if option (b) or (c) is chosen?
3. **Pentium claim.** Neither free candidate identifies a CPU. The edit must not caption or imply "Pentium" over them. Is that acceptable?
4. **Free Art License.** Is its attribution and Article 4 (larger-work) condition acceptable for the final video, if the Commons clip is used?
5. **Resolution.** Is a roughly 2.6× upscale of a 640×416 clip visually acceptable for a brief insert?
