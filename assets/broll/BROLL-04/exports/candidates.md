# BROLL-04 — Browsing a 1990s software store: candidate report

**Status of this report:** the scouting pass, written before any download. **Candidate 1 has since been acquired** (2026-09-15, branch `ticket/BROLL-04-media`) on Devin's approval; candidates 2 and 3 were not. **Nothing is cleared.** Release stays blocked (R14 open). Where this report and `qa.md` Part 2 disagree — above all the out point 00:02:24.0, which does not survive contact with the real file — Part 2 wins.
**Access date for every page below:** 2026-09-15. **Scout:** Claude worker on branch `ticket/BROLL-04`.

## Summary

- **Free stock:** no match. Pexels, Pixabay, Mixkit and Coverr have no genuine 1990s software store footage. Videvo and Pond5 blocked automated access (see the search log).
- **Genuine archival footage:** exists on the Internet Archive as amateur camcorder home videos of the Windows 95 launch (23 Aug 1995) inside CompUSA stores, with shelves of boxed PC software.
  - The item pages state **CC0 1.0**.
  - But the uploader ("The Nostalgist777") is **not** the named creator, and both items name YouTube originals from the creators' own channels.
  - So the CC0 is a third-party assertion whose authority is unverified. It is a legal-risk review question, not a clearance.
- **Broadcast archival:** the NBC5/KXAS 1993 "Comp USA" news clip (UNT) is In Copyright and needs a paid license. Starting rate stated as $90/second. The viewer page showed a CAPTCHA, so it was not viewed.
- **Classification:** every candidate below is *genuine archival* (period camcorder or broadcast). None is a reenactment, modern retro-styled shoot, or AI stand-in. No AI stand-in was generated.
