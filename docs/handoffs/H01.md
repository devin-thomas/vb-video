# H01 — Actual video screen recordings

**Original Tier 3 source:** ASSET_PLAN.md:136; SCRIPT.md:789–793

**Status:** Handoff planned; no gated action performed.

## Purpose
Record genuine smooth editor scrolling or terminal interaction, only when a screen recorder is available and the user has approved any app/permission setup.

## Inputs
TERM-01…TERM-06; XTRA-06; accepted OPS-02 harness; narration timing when available

## Agent-preparable work and handoff steps
1. Confirm capture app, display/region, 1920×1080/30fps target, cursor visibility, and whether system sound should be captured. No microphone capture unless requested.
2. Use an isolated workspace and the same unmodified source/harness provenance as the still tickets. Hide notifications and private windows before recording, not by editing out inconvenient program behavior.
3. Record clean starts/ends and preserve raw footage. A replay of a saved log is useful but must be labeled replay, not a fresh live run.
4. Fallback is the approved screenshot sequence with editor pan/scan. Do not mark that fallback as actual screen recording.

## Actual human/capability boundary
User approval for recording permissions/app setup; an agent may execute the capture only if its environment really supports it.

Original “human-only” wording is preserved as the plan's boundary, not a claim that no authorized future agent can operate the tool. First establish available capabilities and real permission; do not bypass missing access or claim work happened.

## Expected return package
- Raw capture file, screen/region/app/version, frame rate/dimensions, source hash, exact command, take log, and proposed in/out.
- No claim of recorded video without an actual media file and playback check.

## Acceptance and stop rules
- [ ] Required user decisions and permissions are documented.
- [ ] Returned paths refer to real files; source/rights/versions and review results are recorded.
- [ ] No secret, password, token, or unapproved paid action appears in the pack.
- [ ] This handoff is marked complete only for the actual action performed, not for a proposed workaround.

If blocked, record the exact missing file, account permission, decision, or local capability. Do not request the original attachments again; they are already in sources/.
